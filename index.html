WebGIS Pro

Full-featured web mapping workspace

1. Functions / Features in App

  • Basemap and satellite imagery switcher with opacity control and NASA daily imagery by date.
  • Overlay layers and place search, plus go-to-coordinates.
  • Drawing tools: polygon, line, rectangle, circle, marker, with edit and delete.
  • Measure distance and area.
  • Import .zip shapefiles and .geojson files, and manage imported layers.
  • Export to GeoJSON, KML, and Shapefile ZIP.
  • Print map to PDF, copy a shareable view link, and live lat/lng/zoom readout.

2. Stack and Architecture

HTML5CSSJavaScriptLeaflet.jsNASA GIBS imageryVercel

Single-page, client-side app. The map, drawing, measuring, and file import/export all run in the browser, with a side panel of tool tabs (Layers, Tools, Data). Hosted as a static site on Vercel.

PDMS FESCO

Power Distribution Management System with AI asset survey

1. Functions / Features in App

  • Dashboard with filters by circle, division, sub division, grid station, and feeder, plus live counts of feeders, poles, surveys, equipment, and consumers.
  • HT and LT field survey forms: pole number, GPS capture, class, type, and height.
  • HT pole inventory with status and date filters, and a survey pipeline (Draft, Submitted, Under review, Approved).
  • AI Field Asset Scanner: upload or take a photo, and AI marks poles, transformers, and insulators with confidence scores.
  • AI photo review with bounding boxes, confirm or reject each detection, and bulk confirm for high-confidence results.
  • Modules for equipment, consumers, feeders, LT consumer mapping, data search, and reference data.

2. Stack and Architecture

HTML5Tailwind CSSJavaScriptAI Vision API (Gemini)Lucide IconsVercel

Browser-based dashboard with a sidebar for modules. Survey data feeds the dashboard counts and pipeline. Photos go to a vision model that returns detected components, which a reviewer confirms or rejects before they become confirmed records.

3. Link and QR Code

Open app ↗ pdms-cyan.vercel.app

Harborview Explorer

Responsive mobile-first GIS discovery map

1. Functions / Features in App

  • Interactive map with place search by name or by coordinates (for example, a city name or a lat/lng pair).

  • Tap markers to explore sample points of interest.
  • Category filters: Explore, Green spaces, Culture, and Cafés.
  • Reset view button and a layout designed for phones.

2. Stack and Architecture

HTML5CSSJavaScriptLeaflet.jsOpenStreetMapVercel

Lightweight responsive front end with a Leaflet map on OpenStreetMap tiles. Demo points of interest are stored in the page and drive the markers, filters, and the featured place card.
